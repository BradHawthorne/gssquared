# corpus/ — local test inputs (not redistributed)

Disk images, snapshots and injected binaries that gates and consumer harnesses boot or
load. Everything here except this file is ignored by git: the images are Apple system
software or third-party titles and are not redistributed, and a snapshot is tied to the
build that wrote it. Each user supplies their own copies.

| File | Used by | What it is |
|------|---------|------------|
| `gsos601.po` | `tools/a2rail/unarmedhash.ps1` (baseline row `iigs-gsos601`), a2engine `gsoscheck.ps1`, the MEMVU workload sweep, a2vga `m0` validators | GS/OS 6.0.1 32 MB boot volume |
| `gsos602.po` | the MEMVU workload sweep, a2vga `morphiigs.ps1` | GS/OS 6.0.2 800K volume |
| `_finder.po` | Rosetta `ctrl_session_check.py`, `scenarios_smoke.py`; a2engine `gsoscheck.ps1` | boot volume that stops at the Finder splash |
| `cl400.snap`, `cl800.snap`, `cl1600.snap` | the MEMVU workload sweep | GS/OS boot snapshots at 400/800/1600 frames (restore warns when the build differs) |
| `blit_direct.bin`, `blit_shadow.bin` | the MEMVU workload sweep (generated by its blit writer) | synthetic SHR blit workloads for `A2GSPU_RUN_BIN` |
| `silky_classics.2mg` | the MEMVU workload sweep | application volume for the input-driven workload rows |
| `asimov_dealerdemo.po`, `asimov_dealerdemo2.po` | the MEMVU workload sweep | the Apple IIgs Dealer Demo, two disks |
| `_em.po` | the MEMVU workload sweep (row `em-vol`) | a GS/OS volume exercising the Event Manager |
| `mintvol_m0app_cgsos.po` | a2vga `m0/cgsos_validate.ps1` (minted there) | a toolchain-minted test volume |

Point a harness here with its own setting (`A2RAIL_GSOS_IMAGE`, `MEMVU_CORPUS`, …) or the
default path `<repo>/corpus/<file>`. A missing input is a failure with the path named, not a
skipped check.

These files used to sit in the repository root beside ~160 scratch artifacts from driven
sessions (spike dumps, screenshots, debug volumes). The scratch moved out of the tree; run
sessions from a scratch directory, or set `A2GSPU_OUT_DIR` and `A2GSPU_BRAM`, so it does not
accumulate again.
