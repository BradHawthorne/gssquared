# Native feature-shape inventory

All 73 verbs in the current registry appear exactly once. This is an interface/model inventory; the new deep implementation and failure fixtures are identified in the accompanying report. The family/kind is not a claim that every subcommand is read-only.

| Family | Every native verb in this family | Current shape / remaining boundary |
| --- | --- | --- |
| discovery | `copilot`, `help`, `json`, `limitations`, `manifest`, `oracle`, `protocol`, `rail`, `systems` | Runtime native inventory plus MCP adapter discovery; no inference of effects from kind alone. Operation-level typed arguments/preconditions/effect declarations remain incomplete for mixed native verbs. |
| execution | `boot`, `pause`, `pause-status`, `quit`, `reset`, `resume`, `run`, `run-until`, `step` | Validated counts before effects; PC predicate before execution; native completion/reason/work receipts; original reply recovery. Instruction-boundary attempts are a budget, not instruction counts or a wall-clock cancellation guarantee. General predicates still belong to host workflows. |
| cpu-memory | `cpu`, `cycles`, `dis`, `load`, `poke`, `read`, `setreg`, `stack`, `verify` | Named CPU/MMU views and readability; deliberate writes; quoted load inputs; byte-level verification. Many native verbs still use the legacy arguments string and file artifacts; exact decoder/source assumptions must be inspected. |
| instrumentation | `audio`, `callstream`, `capture`, `cov`, `iolog`, `itrace`, `memvu`, `session`, `subscribe`, `tbtrace`, `tbuf` | Explicit arm/status/close, bounded streams and loss counters, scoped artifact retrieval. A file read is not producer-finalization proof; close producers before assertions. Events cover a named subset and sampled device boundaries. |
| device-state | `devstate`, `inspect`, `joymode`, `speaker`, `ui`, `vid` | Native typed fields, coverage declarations and explicit availability/effect receipts. Typed device state is incomplete where declared; physical host UI and actual GPU equivalence remain separate evidence. |
| input | `holdkey`, `input`, `key`, `keys`, `paddle`, `pbutton`, `press` | Owned edges, bounded injection, native readback/consumption labels; macro timeline available. Queue acceptance, consumption and intended guest behavior are different outcomes; not full-machine replay. |
| media | `mount` | Explicit input path and runtime mount verdict; uploaded inputs can be passed deliberately. Configured media and external endpoints can be shared across cold jobs; no automatic storage isolation or per-operation typed effect schema. |
| checkpoint | `diff`, `restore`, `save` | Transactional restore, per-file block manifests and semantic diff/checkpoint companions. Clock/host state/synthesis exclusions prevent full replay or exact branching; never infer completeness from a save succeeding. |
| assertion-calibration | `assert`, `dhgr-calibrate`, `dhgr-export`, `dhgr-golden`, `shr-golden` | Measured verdicts, named rendering profiles, negative fixtures and digest-bound evidence. Calibration success does not prove guest success or real-hardware equivalence; blessing remains deliberate. |
| screen-evidence | `hgr`, `png`, `pngc`, `screen`, `shot`, `shr`, `text`, `vram` | Named RAM/reference rasters and raw text; complete native PNGs become viewable MCP images. Reference pixels are not actual GPU output; SDL BMP remains binary transport without preview; configured glyph extraction is not universal OCR. |
| break-fault | `bp`, `fault`, `trap`, `valtrap`, `watch` | Native stop/fault boundary contracts, timestamps, source ownership and explicit fault limitations. No mid-bus ABORT rollback; provenance traps and memory watches are distinct tools; not exhaustive device-event coverage. |
